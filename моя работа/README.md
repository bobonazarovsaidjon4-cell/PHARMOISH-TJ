# PHARMOISH TJ — прототип кабинета и AI-чата

Проект остаётся существующим HTML-приложением. Новые серверные функции запускаются стандартной библиотекой Python; дополнительные пакеты не нужны. Бренд кабинета — PHARMOISH TJ, имя AI-помощника — FARMOISH AI.

## Запуск локально

В PowerShell из папки проекта:

```powershell
py -3 server.py
```

Откройте `http://127.0.0.1:8765/`. Чат FARMOISH AI доступен по `http://127.0.0.1:8765/dashboard/ai-assistant`.

## Подключение языковой модели

Без ключа endpoint корректно возвращает состояние «временно недоступен» и не имитирует ответ модели. Откройте локальный `.env` и вставьте ключ после `AI_API_KEY=`:

```text
AI_API_KEY=ваш_секретный_ключ
AI_MODEL=gpt-4o-mini
```

Сервер перечитывает `.env` при запросах, поэтому после сохранения файла обновите страницу чата. `.env` исключён из Git. Не вставляйте ключ в HTML, JavaScript, Git или сообщения. Для OpenAI-compatible провайдера можно задать `AI_API_URL`; используйте доверенный HTTPS endpoint. Подписка ChatGPT и баланс API — разные продукты: для API нужна отдельная активная оплата/квота.

API чата ограничивает частоту запросов до 12 в минуту с одного IP, размер тела и историю сообщений. Для размещения в интернете дополнительно необходимы аутентификация и авторизация на backend, HTTPS, постоянное хранилище аудита и production rate limiting.

## Логотип

В брендинге используется SVG-эмблема PHARMOISH TJ из `images/logo.svg`; она масштабируется без искажения пропорций.

## Ограничения прототипа

Маршрут AI-чата поддерживает локальный сервер, но это не Next.js/React-приложение. Настройки и заявки остаются в localStorage, чаты хранятся только в памяти вкладки. Для production нужны PostgreSQL, серверное управление пользователями/ролями и аудит.
